| 1 | `USE_PGLITE_ADAPTER` boolean env var: `z.coerce.boolean()` coerces the literal string `"false"` to `true` (any non-empty string is truthy in JS) | **HIGH** | None needed — a deploy-time misconfiguration, not an external attack. ## Scope note

This phase's security work was a live re-verification pass (spot-checking the mechanisms Phase 19/20 already certified: RBAC via `authorize.ts`, tenant isolation via `enforceWorkspacePathMatch`, error-handling via `error-handler.ts`'s stack-trace-free responses) plus genuinely new live probing (mass assignment, SQL-injection-style payloads, auth rate limiting, oversized/malformed input) that had not been exercised with real curl-based live requests in this exact form before. The two HIGH findings were discovered as a direct result of that live probing surfacing a real 500 that code review alone had not caught in three prior phases.
